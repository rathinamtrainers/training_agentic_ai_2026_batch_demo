# Root Cause Analysis

> Northwind Assurance · Complaints · procedure CMP-15 · reviewed 2026-05-30

## 1. Purpose

To stop the same complaint arriving again. A complaints function that only answers
complaints is an expensive letter-writing department.

## 2. What is analysed

Every upheld complaint, every Ombudsman case whatever the outcome, and any cluster of
three or more complaints in a month sharing a category and a cause.

## 3. The five questions

What happened. What should have happened. Why the gap existed. What change prevents
it. Who owns the change and by when.

## 4. Ownership

The owner is the team that can make the change, not the Complaints team. An action
without a named owner and a date is not an action.

## 5. Follow-up

Open actions are reviewed monthly. An action open for more than 90 days is escalated
to the executive committee with the number of complaints it has caused since it was
raised.
